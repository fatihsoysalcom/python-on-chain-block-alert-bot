# Python On-Chain Block Alert Bot

This Python script demonstrates how to create a basic on-chain alert bot without using any specialized blockchain libraries. It polls a public Ethereum RPC endpoint to fetch the latest block number and prints an 'ALERT' message whenever a new block is detected. This illustrates direct interaction with blockchain data using standard HTTP requests and JSON parsing.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`.
